01 — Marche à suivre

Publier un mod en 3 étapes

Aucun serveur, aucun compte à créer ailleurs : tout se passe sur GitHub.

1

Fork ce dépôt

Bouton Fork en haut à droite de la page GitHub du dépôt. Tu obtiens ta propre copie modifiable.

2

Ajoute ton mod

Publie ton fichier .rsm en Release GitHub, puis ajoute une entrée dans catalog.json avec le lien (voir le format ci-dessous).

3

Propose ta Pull Request

Ouvre une Pull Request vers ce dépôt. Une fois acceptée, ton mod apparaît dans Starynth pour tout le monde.

02 — Référence

Format d'une entrée

Chaque mod est un objet JSON dans catalog.json.

{
  "id": "identifiant-unique",
  "name": "Nom affiché du mod",
  "author": "Ton pseudo",
  "version": "1.0",
  "gameVersion": "1.1.1",
  "description": "Description courte.",
  "tags": ["gameplay"],
  "iconUrl": "https://.../icon.png",
  "downloadUrl": "https://github.com/.../mon-mod.rsm",
  "updatedAt": "2026-07-23"
}
id

Identifiant unique, sans espace ni majuscule accentuée.

gameVersion

Version exacte de SMATRS visée (ex. 1.1.1, 1.0.2). Sert au filtre par version et à la création automatique d'instance dans Starynth.

iconUrl

Lien direct vers un PNG. Tu peux l'héberger dans ce dépôt (dossier icons/) et utiliser un lien raw.githubusercontent.com.

downloadUrl

Lien direct vers le .rsm, publié comme asset d'une Release GitHub — pas un lien vers le code source.
