Publie ton mod en un formulaire

Pas de Git, pas de fork, pas de Pull Request : remplis un formulaire, glisse ton fichier, c'est tout. Ton mod est ajouté au catalogue automatiquement, en quelques minutes.

1

Clique sur "Proposer mon mod"

Ça ouvre un formulaire GitHub classique — connecte-toi à un compte GitHub (gratuit) si besoin.

2

Remplis les infos et glisse ton fichier

Nom, auteur, version, description... et ton .rsm renommé en .zip (indiqué dans le formulaire).

3

Valide — c'est tout

Une automatisation ajoute ton mod au catalogue toute seule. Tu reçois une confirmation directement sur ta demande.
